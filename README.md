# fractol

This program runs only on linux distributions which uses X11 window managment.

Make sure first, you download minilibx and put it here [minilibx](https://github.com/42paris/minilibx-linux#)
You should rename it as "minilibx-linux"

```sh
make
./fractol mandelbrot
./fractol 1.0 .5
```
To learn about fractals check out mandelbrot and julia parts in [complex_analysis](https://complex-analysis.com/content/table_of_contents.html)

Note: To close the program press X.
